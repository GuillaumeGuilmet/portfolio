# Portfolio BTS SIO SISR — Guillaume Guilmet

## Ouverture

1. Décompressez l'archive complète, sans déplacer les dossiers.
2. Ouvrez `index.html` dans Chrome, Edge ou Firefox.
3. Le bouton **Voir mon CV** ouvre `documents/CV_Guillaume_Guilmet.pdf` dans un nouvel onglet.
4. Les vignettes Projets ouvrent les fiches dans le dossier `projets/`.

## Formulaire de contact

Le formulaire est relié à FormSubmit (https://formsubmit.co/) avec l'email affiché dans votre CV.
Pour **l'activer**, publiez le site et faites un premier envoi test ; validez le mail de confirmation envoyé par FormSubmit (vérifiez vos indésirables). Le premier envoi de test peut ne pas être livré avant activation.
Sur un hébergeur comme GitHub Pages, aucun serveur n'est nécessaire. Le service tiers reçoit les données envoyées par les visiteurs.
Le formulaire n'a pas été testé avec une véritable soumission, pour ne pas générer de message non sollicité.

## Protection des données personnelles

Le CV présent dans `documents/` est une **version actualisée** présentant le BTS SIO SISR au CNED, reconstruite à partir des informations du CV fourni. L’adresse postale complète n’y figure pas. Le PDF original fourni n’a pas été modifié.
Le CV et le site affichent toujours votre numéro de mobile et votre email, conformément au besoin de contact du document d'aide. Assurez-vous de vouloir les rendre publics avant mise en ligne. Pour plus de confidentialité, vous pouvez choisir une adresse professionnelle dédiée.
Ne remplacez pas le PDF public par votre original sans supprimer l'adresse de rue.

## Publication

GitHub Pages peut publier ce site statique : transférez le contenu du dossier (y compris `style.css`, `script.js`, `documents/` et `projets/`) dans un dépôt, puis activez Pages dans les réglages du dépôt.
